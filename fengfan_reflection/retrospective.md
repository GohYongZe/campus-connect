1. One Git task you can now complete independently.

I can now independently complete the entire Git workflow, from cloning a repository and creating a branch to making changes, committing and pushing them, and creating a pull request.

2. One useful review comment you gave or received.

One useful piece of feedback I received was about coordinating development tasks with teammates. When our tasks depend on each other, we should wait for the previous pull request to be reviewed and merged before proceeding with the next step. If our local and remote branches are out of sync, force-pushing can overwrite other people's changes and cause code loss.

3. One improvement made after feedback.

After receiving this feedback, I learned to communicate with my teammates before making changes that could affect their work. I will check that everyone is working with an up-to-date codebase and coordinate the timing of commits and pull requests. This will help us reduce conflicts and avoid accidentally overwriting each other's code.

4. One conflict you resolved and how you decided the final content.

One conflict occurred when changes made by different team members affected the same part of the code. We compared both versions, discussed the intended functionality, and agreed on the version that best met the project requirements. This taught me the importance of communicating with teammates and carefully reviewing changes before resolving a merge conflict.

5. One Git skill you would like to practise further.

I would like to practise using Git to restore previous versions of a repository and switch between different versions of the code. In particular, I want to become more confident with commands such as git log, git checkout, git switch, git restore, and git reset, so I can recover from mistakes and manage version history more effectively.
